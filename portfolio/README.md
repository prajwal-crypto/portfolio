# Prajwal Gowda H R — DevOps Portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript.

## Project Structure

```
portfolio/
├── index.html        # Main HTML file (all sections)
├── css/
│   └── style.css     # All styles (dark theme, responsive)
├── js/
│   └── main.js       # Terminal animation, scroll effects, hamburger menu
├── assets/           # Place your profile photo or any images here
└── README.md
```

## Features

- Animated terminal typewriter in Hero section
- Scroll-triggered fade-in animations
- Fully responsive (mobile, tablet, desktop)
- Sticky nav with active section highlight
- Dark theme with cyan accent

## How to Deploy on GitHub Pages

1. Create a new GitHub repo named `prajwalgowdahr.github.io`
2. Push all files to the `main` branch
3. Go to repo **Settings → Pages → Source → main branch → / (root)**
4. Your site will be live at: `https://prajwalgowdahr.github.io`

## Customizations to Make

Before deploying, update these in `index.html`:

- Line ~80: Replace Flipkart Clone `<a href="#">` with your actual live URL
- Line ~83: Update GitHub links with your actual GitHub username
- Line ~140: Update LinkedIn URL with your actual profile
- Add your resume PDF to `assets/` and link it in the Hero section

## Local Preview

Just open `index.html` in any browser — no build step needed.
